# FloatingClock

Windows용 오프라인 고정밀 시계입니다. 인터넷/NTP를 쓰지 않고, Windows API `GetSystemTimePreciseAsFileTime`으로 로컬 시스템 시각을 100ns 단위로 읽습니다.

테두리 없는 **창 모드**로 동작합니다. 드래그하면 시계 글자가 아니라 **창 전체**가 이동합니다.

## 요구 사항

- Windows 10/11
- Python 3.11 이상 (소스 실행 시)
- PySide6

## 소스 실행

```bat
python -m pip install -r requirements.txt
python main.py
```

## exe 빌드

`build.bat`을 실행하면 단일 파일 exe가 만들어집니다.

```bat
build.bat
```

결과물: `dist\FloatingClock.exe`

배포 옵션은 PyInstaller `--onefile --noconsole` 입니다. `settings.json`은 exe와 같은 폴더에 생성됩니다.

## 화면

- 검정 배경 + 빨간 글자, 프레임 없는 창
- 기본: `2026년 09월 16일 수요일` / `14:05:09.123`
- 왼쪽 드래그: 창 이동
- 우클릭: 편집·표시 방식 메뉴
- 편집 모드에서 가장자리/모서리 핸들로 창 크기 조절 (`Shift` + 모서리는 비율 유지)

## 우클릭 메뉴

| 항목 | 내용 |
| --- | --- |
| 편집 모드 | 리사이즈 핸들·가이드 표시 |
| 날짜 표시 | 날짜 줄, 년도, 월/일, 요일 on/off |
| 시각 표시 | 24/12시간제, 초, 소수점 없음/밀리초/마이크로초 |
| 항상 위 | 다른 창 위에 고정 |
| 마우스 커서 숨김 | 커서 숨김 |
| 모니터 | 연결된 모니터로 창 이동 |
| 위치/크기 초기화 | 기본 크기·현재 모니터 중앙 |
| 종료 | 프로그램 종료 |

## 단축키

| 키 | 동작 |
| --- | --- |
| `Esc` | 종료 |
| `F11` | 현재 모니터에 맞춤 / 이전 크기 |
| `1`–`9` | 해당 번호 모니터로 이동 |
| `E` | 편집 모드 토글 |
| `M` | 소수점 없음 → 밀리초 → 마이크로초 순환 |
| `R` | 위치·크기 초기화 |
| `H` | 마우스 커서 숨김 토글 |
| `T` | 항상 위 토글 |

## 설정

창 위치/크기, 모니터 번호, 날짜·시각 표시 옵션, 항상 위, 커서 숨김을 `settings.json`에 저장합니다. 저장된 모니터가 없으면 주 모니터로 돌아갑니다.
